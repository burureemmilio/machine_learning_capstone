#  Used Car Price Prediction
## Problem Statement
 - The used car market contains vehicles with different characteristics such as
brand, model, age, mileage, fuel type, engine, transmission, and accident history.
These factors can have a significant influence on the selling price of a vehicle.

 - For buyers and sellers, estimating a fair market price can be difficult because
the relationship between these characteristics and price is not always simple.

 - This project aims to develop machine learning regression models that can predict
the selling price of a used car based on its characteristics.

## Objective
 - The main objective of this project is to build, evaluate, and compare multiple
machine learning regression models and determine which model provides the most
accurate used-car price predictions.

## Models

 - The following regression models will be compared:

1. Linear Regression
2. Ridge
3. Random Forest
4. K-Nearest Neighbors Regression
5. XGBoost
6. HistGradientBoost

## Evaluation Metrics
 The models will be evaluated using:
 - Mean Absolute Error (MAE)
 - Root Mean Squared Error (RMSE)
 - R² Score

The best-performing model will be selected based on its predictive performance
on unseen test data.
